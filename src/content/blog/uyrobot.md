<p>A project I’m very proud to have been involved with is finally live: <a href="http://www.uyrobot.com.uy/">UYRobot</a>. Among other things, they teach both kids and adults how to build robots.</p>

            <p>The site was a collaborative effort with designer <a href="https://www.flaviacalandria.com/">Flavia Calandria</a>.</p>

            <p>The tech used was React (through Create React App) &amp; SASS, with Express on the backend. Although I’m currently thinking of migrating it to Next.js to provide server side rendering. The site is also hosted on Heroku for staging.</p>

            <p>The full source code of the site is available on <a href="https://github.com/HiroAgustin/uy-robot/">GitHub</a>.</p>
